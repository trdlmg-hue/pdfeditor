Tips

  • Double-click a word to edit just that word. Hold Alt or Shift while double-clicking to replace the whole line (or one table cell).
  • Uncheck Cover replaced text with a patch to get transparent text, then move it anywhere. No patch removes the patch under the selected text.
  • Tables panel: the pencil makes every cell editable, CSV saves the values, the download button saves the table image. The Table tool inserts a new editable table (rows × columns, fill, border and page size). Click any cell to select the table, drag to move it as one unit; double-click a cell to type in it.
  • Use the Detach tool (D) or the scissors buttons to peel stacked images one layer at a time. Each layer can be saved as a PNG from the Layers panel.
  • Pages opens a thumbnail grid: rotate, reorder, delete, add blank pages or insert pages from another PDF or image.
  • Merge / Split combines several PDFs in drag order, or splits this document into ranges, chunks or single pages.
  • Background removes a page or image background with the magic wand, lasso or smart select, then keeps it transparent or replaces the page.
  • Signature lets you draw, type (with a font) or upload a signature, save it for reuse and place it on the page.
  • Select any layer to type an exact angle, lock it against accidental edits, or hide / reorder it in the Layers panel. Drag the round handle above a selection to rotate it with the mouse, or pick the Rotate tool (G) and drag the object itself.
  • Use Patch to paint over anything that must disappear.
  • Arrow keys nudge the selection by 1 pt (hold Shift for 10 pt).
  • Ctrl+Z undo, Ctrl+S export.
